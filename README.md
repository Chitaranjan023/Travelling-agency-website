# WanderLust | Responsive Travel Agency Website

A modern, clean, and fully responsive travel agency landing page built with HTML5, CSS3, and Vanilla JavaScript. Designed to showcase global and Indian destinations with a focus on mobile-first user experience.

## 🚀 Features

- **Mobile-First Design:** Fully responsive layout that adapts to Mobile, Tablet, and Laptop screens.
- **Interactive Navigation:** Sticky glassmorphism navbar with a functional hamburger menu for mobile devices.
- **Booking System:** Integrated booking modal (popup) for user lead generation.
- **Destination Showcase:** Curated grid layout featuring high-quality images of global and Indian destinations (including Puri, Ladakh, and Kerala).
- **Contact Integration:** Clean contact form with validation and user feedback.
- **Smooth Animations:** Hover effects, scroll transitions, and modal entry animations for a premium feel.

## 🛠️ Built With

- **HTML5:** Semantic structure for SEO and accessibility.
- **CSS3:** Custom properties, Flexbox, and CSS Grid for layout management.
- **JavaScript (ES6+):** Functional modal logic, mobile menu toggles, and scroll effects.
